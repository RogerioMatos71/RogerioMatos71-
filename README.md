## Projetos

### 1. Library System DAO

Sistema de gerenciamento de biblioteca desenvolvido como projeto de estudo para praticar Java e persistência de dados.

**O que venho praticando:**
- Modelagem de usuários, livros, exemplares e empréstimos.
- Acesso ao MySQL por meio de JDBC.
- Aplicação do padrão DAO para separar o acesso a dados das demais responsabilidades.
- Organização em camadas, com DAOs, serviços e controle da aplicação.
- Uso de Git e GitHub para controle de versão.

**Tecnologias:** Java, JDBC, MySQL, SQL, Maven e Git.

### 2. PrinterAgent

Projeto Java em desenvolvimento para estudar a coleta de contadores e informações de impressoras em rede por meio de SNMP.

**O que venho praticando:**
- Comunicação SNMP com impressoras e simulador.
- Leitura de OIDs para obter informações e contadores.
- Organização do projeto com Maven e configuração externa.
- Desenvolvimento e estudo de persistência de leituras.
- Planejamento de coleta periódica, histórico de leituras e alertas em caso de falhas.

**Tecnologias:** Java, SNMP4J, SNMP, Maven e JPA.

> O PrinterAgent está privado enquanto continua em desenvolvimento.

### 3. Plataforma de Organização Financeira

Projeto em fase de planejamento para organizar informações financeiras e facilitar a conciliação de documentos fiscais eletrônicos.

**Ideias em desenvolvimento:**
- Importação de arquivos XML de NFC-e.
- Extração e armazenamento de dados estruturados.
- Regras para identificação de documentos já importados.
- Organização da aplicação e persistência em banco de dados relacional.

**Tecnologias previstas:** Java, MySQL, Spring Boot e JPA.
